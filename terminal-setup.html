01
Install iTerm2 — a better terminal
App
Replace the default Terminal.app with iTerm2. It supports true 24-bit colour, split panes, image display, and far more customisation.
brew install
brew install --cask iterm2
💡 Don't have Homebrew? First run:
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
Then open iTerm2 → Preferences → Profiles → Colors tab to pick a colour scheme.
02
Install Oh My Zsh + plugins
Shell
Oh My Zsh is a framework that manages Zsh config, themes, and plugins. It's the backbone of a beautiful shell.
install oh-my-zsh
sh -c "$(curl -fsSL https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"
Then install these two essential plugins:
plugins
# Syntax highlighting (colours your commands) git clone https://github.com/zsh-users/zsh-syntax-highlighting \ ${ZSH_CUSTOM:-~/.oh-my-zsh/custom}/plugins/zsh-syntax-highlighting # Autosuggestions (grey text completions) git clone https://github.com/zsh-users/zsh-autosuggestions \ ${ZSH_CUSTOM:-~/.oh-my-zsh/custom}/plugins/zsh-autosuggestions
Enable them in ~/.zshrc:
~/.zshrc
plugins=(git zsh-syntax-highlighting zsh-autosuggestions)
03
Install Powerlevel10k theme
Prompt
Powerlevel10k (p10k) is the most beautiful and fastest Zsh prompt theme — it shows git status, execution time, errors, virtualenvs, and more.
install p10k
git clone --depth=1 https://github.com/romkatv/powerlevel10k.git \ ${ZSH_CUSTOM:-$HOME/.oh-my-zsh/custom}/themes/powerlevel10k
Set it as your theme in ~/.zshrc:
~/.zshrc
ZSH_THEME="powerlevel10k/powerlevel10k"
✦ After saving, restart your terminal and run p10k configure to go through an interactive wizard that lets you pick icons, colours, and layout — it's incredibly well designed.
04
Install a Nerd Font
Fonts
Nerd Fonts patch developer fonts with thousands of icons — they're required for Powerlevel10k's arrows, git icons, and status symbols to render correctly.
install font
# MesloLGS NF — recommended for p10k brew tap homebrew/cask-fonts brew install --cask font-meslo-lg-nerd-font
⚠ After installing, go to iTerm2 → Preferences → Profiles → Text → Font and set it to MesloLGS NF. Without this, icons will show as broken boxes.
05
Apply a colour scheme
Colours
Popular colour schemes to download from iterm2colorschemes.com and import via iTerm2 → Preferences → Profiles → Colors → Import:
Tokyo Night
Dracula
GitHub Dark
Catppuccin
Also add lsd (a colourful ls replacement) and bat (colourful cat):
colourful tools
brew install lsd bat # Add to ~/.zshrc alias ls="lsd" alias cat="bat"
✦ After all steps: run source ~/.zshrc to reload, then p10k configure to fine-tune your prompt.
✦ Visit iterm2colorschemes.com for 250+ colour schemes to browse and download.
